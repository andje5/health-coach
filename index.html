Importera från Genväg
Genvägen kan öppna den här appen med ett JSON-paket i länken. Du kan även klistra in JSON manuellt här.
Format för Genvägen
Skicka ett JSON-objekt med fälten: steps, activeEnergyKcal, exerciseMinutes, sleepHours, restingHeartRate, hrvMs, vo2Max, latestWorkoutMinutes och valfritt week (7 objekt med label + steps).
Data lagras bara lokalt i webbläsaren på enheten i denna version.
