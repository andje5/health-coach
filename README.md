
# Health Coach PWA v2

Fokus: viktminskning genom gång/promenerande, sömn och hållbara vanor.

Nyheter:
- Viktkort med mål 95 kg
- Dagens steg
- Promenadminuter
- Aktiva kalorier
- Sömn, vilopuls, HRV och VO2 max
- Dagens status
- Fyra tydliga mål
- Coach-insikter
- URL-import från Apple Genvägar

Publicering:
Ersätt filerna i ditt GitHub-repository `health-coach` med dessa filer och committa.
GitHub Pages uppdaterar sedan sidan automatiskt.

Viktigt:
PWA:n kan inte läsa HealthKit direkt. Synkningen sker genom Apple Genvägar.
